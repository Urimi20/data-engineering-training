# Day 3 SQL Foundations Practice

This folder contains SQL practice completed during the Unity Tech Hub x Agilyti Data Engineering / Databricks training.

The purpose of this practice was to learn the foundations of SQL, work with databases, create tables, insert data, and write queries to extract useful information.

## Files

- `setup.sql` - Creates the orders table and inserts sample data.
- `sql_practice.sql` - Contains SQL queries for practicing filtering, sorting, and selecting data.
- `custom_business_table.sql` - Contains a custom business table with related SQL queries.
- `pipeline_thinking.md` - Explains the data pipeline flow for a chosen business.
- `daily_report.txt` - Short summary of the work completed during the day.
