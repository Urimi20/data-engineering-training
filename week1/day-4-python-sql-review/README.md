# Day 4 - Python and SQL Logic Review

## Goal of the practice

The goal of this practice was to understand how the same data processing tasks can be completed using both Python and SQL.
I practiced filtering data, calculating values, sorting records, and creating simple business summaries using an orders dataset.

## Files included

* `python_orders.py` - Contains Python functions for processing orders, filtering data, calculating totals, sorting, and creating summaries.
* `setup.sql` - Creates the orders table and inserts the sample dataset.
* `sql_queries.sql` - Contains SQL queries for filtering, sorting, calculations, and analysis.
* `comparison.md` - Explains the differences between Python and SQL approaches for the same tasks.
* `daily_report.txt` - Contains a short report about the work completed during the practice.

## How to run python_orders.py

1. Open the project folder in the terminal.
2. Make sure Python is installed.
3. Run the file using:

```bash
python python_orders.py
```

The results will appear in the terminal.

## SQL practice

SQL was practiced using SQLiteOnline.com.
The orders table was created, data was inserted, and queries were tested directly in the SQLite environment.

## What I learned from comparing Python and SQL

I learned that Python and SQL can solve similar data processing problems but in different ways.
Python uses loops, conditions, and functions to process data step by step, while SQL uses queries with commands like WHERE, ORDER BY, GROUP BY, COUNT, and SUM to work directly with tables.

Comparing both helped me understand how data engineers can choose the right tool depending on the task.
